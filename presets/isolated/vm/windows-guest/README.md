# Windows ゲスト（評価対象が Windows アプリのとき）

Windows ゲストは Linux ゲストと違い、Microsoft のライセンス済みメディアが必要で、自動配布できる公式 cloud image がありません。
このリポジトリには**メディアも認証情報も入れません**。ひな形は設計と手順のみです。

## 方針（Linux ゲストと同じ）

- 既定はオフライン。内部スイッチのみ。統合サービス・共有フォルダ・クリップボードは無効。
- 管理は SSH ではなく **ホストからの PowerShell Direct**（`Invoke-Command -VMName`）を使う。Hyper-V の Windows ホストのみ。
  PowerShell Direct はゲストのネットワークを使わずに動くが、ホスト↔ゲストの経路にもなるので、評価中は使わず、投入と回収だけに限定する。
- 評価用ユーザーのパスワードは**配備時に生成**し、ホスト側の保護された場所にだけ保存する。リポジトリ・ログ・チャットに出さない。
- 計測はゲストの外（ホストのネットワーク記録、VM のディスク差分）と、ゲスト内の監査（プロセス作成 4688、ファイル監査 4663）の両方。
  ゲスト内の記録は改ざんされうるため、外側の記録を正とする。

## 手順の骨子

1. Microsoft のライセンス済み ISO（Windows 11 Enterprise 評価版など、利用規約に沿うもの）を人が用意する。
2. `autounattend.template.xml` の `__LAB_ADMIN_PASSWORD__` を配備スクリプトで生成した値に置換して、小さな ISO／VHDX として添付する。
3. Hyper-V 第2世代 VM（Secure Boot、仮想 TPM）を `hyperv/New-AsgLabVm.ps1` と同じ設定（内部スイッチ、統合サービス無効、時刻同期のみ）で作る。
   現状のスクリプトは Linux cloud image 用なので、Windows 用に `-Os Windows` を追加する作業が残っている（未実装）。
4. 初期設定の完了後、`baseline-clean` チェックポイントを作り、評価ごとに復元する。
